# demo仓库说明

## 1、一个Skill：import-doc-checker

进口报关前，单证员需要逐字段比对商业发票、装箱单、提单：品名、件数、毛重净重、金额、HS 编码、计量单位。一票 3-5 项商品，人工核对约 15-20 分钟，客户改单后还要重核一遍。

这个 Skill 接收三份单据的数据，自动跑 20 项检查，1 秒内输出：

- 一份可视化审核看板（HTML，红黄绿分级）
- 一份可留档的差异明细（Excel / CSV）
- 一段可以直接发给单证员的中文问题清单
