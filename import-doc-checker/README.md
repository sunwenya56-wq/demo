# 进口报关三单一致性审核 Skill

把「发票 / 装箱单 / 提单逐字段人工核对」做成一条命令出报告的确定性工具。

> 输入三份单据的结构化数据，输出 HTML 审核看板 + Excel 差异报告，20 项检查覆盖单号、金额、件数、重量、品名、HS 编码、计量单位。

## 为什么做这个

进口报关前，单证员要拿着商业发票、装箱单、提单逐字段比对：品名对不对得上、件数是不是 100 箱、毛重有没有超差、HS 编码位数对不对。一票单子 3-5 个商品，人工核一遍 15-20 分钟，客户改单后还得再核一遍。漏看一个件数，轻则改单重报，重则查验滞港。

这件事的特点是：**规则明确、字段固定、重复度极高、错一次代价很大**——正好适合做成 Skill。

## 效果

用 `data/sample_01`（一票 3 项商品的法国葡萄酒进口单证）实测：

```
核对项：20  通过：12  提示：1  预警：3  错误：4
审核结论：不通过
```

自动检出：

| 级别 | 问题 |
|---|---|
| 错误 | 装箱单 100 箱 ≠ 提单 99 箱，存在短装或提单笔误 |
| 错误 | 发票明细合计 18,350.00 ≠ 发票总额 18,500.00，差额 -150.00 |
| 错误 | 第 2 项 750ml 瓶装静态葡萄酒误用 2204.10（起泡酒）编码，应为 2204.21 |
| 错误 | 第 3 项 HS 编码只有 9 位，不足 10 位申报要求 |
| 预警 | 提单毛重比装箱单高 1.37%，需确认是否含托盘重量 |
| 预警 | 第 3 项品名相似度 85.7%，装箱单混入了 "Red" 备注 |
| 预警 | 发票单位为 BTL、装箱单为 CARTON，需按 12 支/箱换算 |

其中 HS 归类那条（2204.10 → 2204.21）需要报关业务知识才能判断，规则已沉淀在 `config/rules.json` 里。

## 快速开始

```bash
# 无第三方依赖，Python 3.8+ 直接跑
python run.py --case data/sample_01/case.json

# 可选：安装 openpyxl 后自动导出 xlsx，否则降级为 CSV
pip install -r requirements.txt
```

输出：

- `output/核对报告_HJ-2026-1118-001.html` —— 单文件看板，浏览器直接打开
- `output/核对报告_HJ-2026-1118-001.xlsx` —— 汇总页 + 明细页，可直接发主管留档

退出码：有错误返回 `2`，无错误返回 `0`，可接入批处理或定时任务。

## 核对项清单

| 类别 | 核对项 | 判定方式 |
|---|---|---|
| 单号 | 发票号、合同号 | 去空格转大写后完全一致 |
| 主体 | 发货人、收货人 | 编辑距离相似度，≥95% 通过 |
| 日期 | 发票日期 vs 装船日期 | 发票不得晚于装船 |
| 数量 | 件数、明细数量合计、箱数合计 | 绝对误差 ≤ 0.01 |
| 金额 | 明细合计 vs 发票总额 | 绝对误差 ≤ 0.01 |
| 重量 | 毛重偏差、净重合理性 | 偏差 >0.5% 预警、>2% 判错 |
| 品名 | 发票 vs 装箱单逐项 | 相似度 ≥95% 通过，80%-95% 人工确认 |
| 编码 | HS 位数、品名归类、包装归类 | 10 位数字 + 前缀规则 |
| 单位 | 发票 vs 装箱单 | 不一致时提示按规格换算 |

阈值全部在 `config/rules.json`，改配置不用改代码。

## 设计取舍：为什么不让大模型算数

这是这个项目最重要的一个决定。

- **数值、单号、HS 编码走确定性规则**。大模型擅长理解和表达，不擅长精确计算与逐位比对；把金额核对交给模型，是"看起来对、实际算错"的高发区。
- **模型只做两件事**：把规则结果组织成单证员能读懂的中文说明；对需要业务判断的预警给出处理建议。
- **每条结论可追溯**：报告里写清楚比了哪两份单据、差多少、触发了哪条阈值。报关是要留档的，不能给一个"AI 说没问题"。

换句话说：**规则负责说真话，模型负责说人话。**

## 目录结构

```
import-doc-checker/
├── run.py                 # 命令行入口
├── doccheck.py            # 核心逻辑：加载、比对、报告生成（纯标准库）
├── config/rules.json      # 阈值与 HS 归类规则
├── data/sample_01/
│   └── case.json          # 样例单证数据
├── output/                # 生成的报告（已 gitignore）
├── SKILL.md               # Skill 定义，供 Agent 调用
└── requirements.txt       # 唯一可选依赖：openpyxl
```

## 已知限制

- 当前输入是结构化 JSON，PDF 需先经 OCR 或人工录入
- HS 归类规则覆盖葡萄酒、威士忌、橄榄油等常见品类，新品类需补配置
- 不核对原产地证、卫生证书等随附单证
- 审核结果为辅助工具，最终申报以报关员复核和海关认定为准
